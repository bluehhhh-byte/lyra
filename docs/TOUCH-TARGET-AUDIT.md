# 모바일 터치 목표 감사

범위: 공개 화면의 핵심 동선, 뷰포트 639px 이하. 기준은 CSS 44×44px(`h-11`, `w-11`, `min-h-11`)이다.

| 위치 | 기존 크기 | 조치 |
| --- | ---: | --- |
| 헤더 검색 | 높이 32px | 최소 높이 44px |
| 헤더 테마·관리자·전체 메뉴 | 32×32px | 최소 44×44px |
| 모바일 전체 메뉴 링크 | 높이 약 36px | 최소 높이 44px |
| 검색 닫기·최근 검색·빈 결과 동작 | 높이 약 24~36px | 최소 높이 44px |
| 가사 보기 모드·독음 | 높이 약 26px | 최소 높이 44px |
| 가사 글자 크기 | 약 26×24px | 44×44px |
| 구절 복사·캐러셀 아이콘 | 약 23×23px | 최소 44×44px |
| 고정 플레이어 제어 | 32×32px, 재생 40×40px | 44×44px |

본문 안의 일반 텍스트 링크와 카드 전체 링크는 작은 아이콘 목표가 아니며, 카드·목록 행 자체의 높이가 이미 44px 이상이라 별도 확대하지 않았다. 관리자 전용 화면은 이 공개 모바일 감사 범위에서 제외한다.
