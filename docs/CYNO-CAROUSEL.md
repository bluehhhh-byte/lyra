# Cyno 영화 캐러셀

## 제품 결정

Cyno 캐러셀은 공개 감상 기능이 아니라 계정 소유자가 Instagram 발행물을 만드는 **관리자 도구**다. 제작실은 `/admin/cyno-carousel`에만 두며 기존 관리자 인증 쿠키가 없으면 로그인 화면으로 이동한다. 공개 `/movies`와 영화 상세에는 제작 버튼이나 제작용 데이터가 나타나지 않는다.

제작 방식은 두 가지를 분리한다.

1. **한 편 깊이 보기** — 기본 흐름. 영화 한 편을 골라 작품 설명형 5장을 만든다.
2. **주제별 큐레이션** — 보조 흐름. 키워드나 발행 콘셉트로 여러 작품을 자동 선정한다.

두 방식은 같은 화면과 저장 장치를 쓰지만 콘텐츠 계약은 섞지 않는다. 한 편을 설명해 달라는 요청에 별점 목록을 만들거나, 여러 편을 묶는 요청에 한 영화의 줄거리만 반복하지 않는다.

## 한 편 깊이 보기

### 5장 계약

1. **표지** — 포스터, 작품명, 감독, 연도
2. **기본 설명** — 감독·연도·러닝타임·장르·출연진과 짧은 작품 소개
3. **줄거리** — 저장된 Cyno 상세 본문을 읽기 좋은 분량으로 배치
4. **주요 내용** — 줄거리의 핵심 문장과 작품 주제를 최대 세 항목으로 정리
5. **감상 포인트** — 연출·장르·주제·배우를 중심으로 볼 지점과 기존 작품 노트

영화를 선택하는 즉시 저장된 줄거리, 코멘트, 태그와 주제로 초안을 만든다. 모든 문구는 제작 화면에서 수정할 수 있고 수정 결과는 미리보기에 다시 반영된다. 원본 영화 레코드는 변경하지 않는다.

자료가 부족해도 카드 수를 조용히 줄이지 않는다. 줄거리가 없으면 기본 설명을 재사용하고, 주제나 출연진이 없으면 인물의 선택과 장면의 리듬처럼 사실을 단정하지 않는 감상 안내를 사용한다.

## 주제별 큐레이션

고정된 `★5`, `2000년대` 버튼 대신 관리자가 직접 키워드나 콘셉트를 입력한다. 서버는 다음 필드를 비교해 관련도 점수를 계산한다.

- 제목과 원제
- 감독
- 국가, 장르, 연도, 별점
- 태그와 정서 주제
- 저장된 줄거리와 기존 감상문

관련도 점수, 별점, 연도 순으로 최대 18편을 선정한다. 결과는 표지 1장, 목록 3장, 선정 노트 1장의 5장으로 만든다. 제작 화면에는 전체 후보 수와 실제 선정 작품을 먼저 보여 주므로 저장 전에 주제 적합성을 검수할 수 있다. 일치 작품이 없으면 임의의 인기 영화를 채우지 않고 명확한 오류를 보여 준다.

## 제작 화면 UX

1. 영화 관리자 `/admin/movie`에서 `Cyno 캐러셀 제작실`로 이동한다.
2. 기본 탭은 `한 편 깊이 보기`다.
3. 제목·감독·연도로 영화를 검색하고 한 편을 선택한다.
4. 자동 작성된 다섯 장의 문구를 필요한 만큼 수정한다.
5. 오른쪽 미리보기와 다섯 개 썸네일로 발행 순서를 확인한다.
6. `PNG 5장 저장`으로 모바일 공유 시트 또는 순차 다운로드를 사용한다.
7. Instagram 캡션을 복사해 게시한다.

모바일에서는 편집과 미리보기가 한 열로 쌓인다. 모든 그리드 자식은 축소 가능하고 큰 미리보기는 `max-width: 100%`와 제한된 화면 높이를 사용해 390px 문서 폭을 넓히지 않는다.

## 시각 시스템

- 모든 출력은 Instagram 세로형 `1080×1350` PNG다.
- 배경은 포스터 색을 흐리게 확장한 어두운 중성색이다.
- 포인트는 Cyno 연보라 한 색으로 제한한다.
- 본문은 Pretendard 계열, `Cyno.` 서명은 serif 계열을 사용한다.
- 안전 여백은 84px이며 모든 장에 페이지 번호와 5단계 진행 표시를 둔다.
- 포스터는 `/api/img` 동일 출처 프록시를 거치며 최대 5개만 병렬 로딩한다.
- 포스터가 실패하면 제목 첫 글자가 남는 대체 카드로 계속 생성한다.

## 보안과 무료티어

- `/admin/cyno-carousel`과 큐레이션 API는 기존 middleware의 `/admin/:path*`, `/api/admin/:path*` 인증 경계 안에 있다.
- 공개 페이지는 제작용 상세 레코드나 왓챠 전량을 직렬화하지 않는다.
- 한 편 모드는 관리자 페이지가 이미 읽은 상세 영화만 브라우저에 전달한다.
- 1,000편 규모의 큐레이션 후보는 브라우저에 보내지 않고 관리자 API에서 점수화한 최대 18편만 반환한다.
- 새 DB 테이블, migration, 환경변수와 외부 패키지는 필요 없다.
- PNG는 브라우저에서 만들며 서버에 파일을 저장하지 않는다.

## 검증과 배포

배포 전 다음을 확인한다.

1. 공개 `/movies`에 캐러셀 버튼이 없다.
2. 로그아웃 상태의 `/admin/cyno-carousel`은 `/admin/login`으로 이동한다.
3. 실제 영화 한 편으로 다섯 역할의 PNG가 모두 `1080×1350`인지 확인한다.
4. 키워드 검색 결과가 관련 영화를 먼저 고르고 일치하지 않을 때 실패하는지 확인한다.
5. 390px 모바일에서 `documentElement.scrollWidth === innerWidth`인지 확인한다.
6. `pnpm test`, `pnpm lint:data`, `pnpm build`, `pnpm smoke`를 통과시킨다.

배포는 최신 `origin/main`의 깨끗한 worktree에서 Vercel production으로 한 번만 실행한다. 새 저장 구조가 없으므로 회귀가 있으면 직전 production deployment로 되돌리면 된다.
