# 감정 모델 — valence·arousal 좌표와 아카이브 정서 유형

아카이브의 감정 궤도(`lib/emotion-model.js`)가 쓰는 좌표계와 판정 규칙, 그리고 그
근거·한계를 기록한다. 코드와 이 문서가 어긋나면 코드가 아니라 문서를 고칠 게 아니라
**둘을 같이** 고친다 — 경계값이 테스트(`lib/emotion-model.test.mjs`)에 박혀 있다.

## 참고한 연구

- **Russell, A Circumplex Model of Affect** (DOI: 10.1037/h0077714) — 감정을
  valence(불쾌↔유쾌)와 arousal(저각성↔고각성)의 원형 공간에 놓는다. 궤도 차트의
  두 축이 여기서 온다.
- **Watson·Clark·Tellegen, PANAS** (DOI: 10.1037/0022-3514.54.6.1063) — 긍정 정서와
  부정 정서는 단일 축의 양끝이 아니다. 그래서 한 달을 valence 하나로 접지 않고
  감정 **분포**(다양성·혼재)를 별도로 보여준다.
- **Geneva Emotion Wheel** (Scherer et al.) — 감정 어휘를 원 둘레에 의미 있는 순서로
  배치한다. 감정 구성 차트가 가나다순이 아니라 circumplex 각도로 배치하는 근거.
- **Bradley & Lang, Self-Assessment Manikin** (DOI: 10.1016/0005-7916(94)90063-9) —
  valence·arousal·dominance의 간결한 자기보고 측정. **우리 데이터에는 자기보고가
  없으므로** SAM 점수처럼 표시하지 않고, dominance 축은 아예 다루지 않는다.

## 좌표 (범위 각 -3..+3)

valence는 `lib/keywords.js`의 `EMOTION_VALENCE`를 재사용한다(다이어리 세로축과 동일).
arousal은 `lib/emotion-model.js`의 `EMOTION_AROUSAL`에 정의한다.

| 감정 | valence | arousal | 근거 | 한계 |
|---|---|---|---|---|
| 기쁨 | +3 | +2 | 전형적 고각성 긍정(Russell의 excited~happy 영역) | 잔잔한 기쁨도 있다 |
| 사랑 | +3 | +1 | 긍정이지만 기쁨보다 차분한 경우가 많은 어휘 사용 | 격정적 사랑은 더 높다 |
| 희망 | +2 | +1 | 미래 지향의 완만한 상승 정서 | |
| 설렘 | +2 | +2 | 기대에 의한 각성 상승(anticipation) | |
| 위로 | +1 | -2 | 진정·안정을 주는 저각성 긍정(calm~content) | 받는 위로/주는 위로 구분 없음 |
| 회상 | 0 | -2 | 차분한 되돌아봄, 밝기는 내용에 따라 갈려 중립 | 슬픈 회상도 있다 |
| 몽환 | 0 | -1 | 낮게 떠 있는 비현실감, 밝기 판단 유보 | |
| 그리움 | -1 | -1 | 부드러운 결핍감, 저각성 | 사무치는 그리움은 더 어둡다 |
| 이별 | -3 | -1 | 상실 직후의 어두움, 격앙보다 가라앉음이 많은 수록곡 경향 | 이별 직전의 격앙은 못 담는다 |
| 슬픔 | -3 | -2 | 전형적 저각성 부정(sad~depressed 영역) | |
| 고독 | -2 | -2 | 저각성 부정, 슬픔보다 덜 어둡게 | |
| 체념 | -1 | -3 | 각성이 가장 낮은 어휘 — 놓아버림 | valence는 해석에 따라 더 어두울 수 있다 |
| 불안 | -2 | +2 | 고각성 부정(tense~nervous) | |
| 분노 | -2 | +3 | 가장 높은 각성의 부정 정서 | |
| 저항 | -1 | +3 | 분노만큼 각성이 높지만 방향이 있어 덜 어둡게 | 긍정적 저항(연대)도 있다 |

공통 한계: **음악·영화 선택은 심리검사 응답이 아니다.** 좌표는 곡에 붙인 한 단어
감정 태그를 평면에 놓은 근사이고, 그 달 사람의 정신 상태 측정이 아니다. 결과 문장은
반드시 기록(아카이브)을 주어로 쓴다. 임상 용어(우울증·불안장애 등)는 쓰지 않는다.
영화는 감정 태그가 없으므로(주제 어휘만 있다) 궤도 계산에 넣지 않는다 — 영화 주제를
음악 감정으로 변환하지 않는다.

## 월별 좌표 계산

- 점 위치 = 그 달 **감정 태그가 있는 곡들**의 좌표 평균 (`emotionCenter`)
- 감정 없는 곡은 (0,0)으로 넣지 않고 표본에서 뺀다 — 중심을 중립으로 끄는 왜곡 방지
- 점 크기 = 그 달 기록량, 투명도·링 = 표본 충분성(3곡 미만은 흐리게)

## 아카이브 정서 유형 (`moodType`)

연속 좌표에서 파생되는 설명형 라벨. 고정 성격 분류가 아니다.

| 조건 | 유형 |
|---|---|
| 표본 3곡 미만 | 판단 유보 |
| \|v\|<0.5 이고 \|a\|<0.5, entropy≥0.75 | 복합 정서 |
| \|v\|<0.5 이고 \|a\|<0.5 | 몽환적 유예 |
| \|v\|<0.5, a>0 | 흔들리는 탐색 |
| \|v\|<0.5, a≤0 | 몽환적 유예 |
| v>0, a≥0 | 밝은 확장 |
| v>0, a<0 | 고요한 회복 |
| v<0, a≥0 | 긴장된 저항 |
| v<0, a<0 | 깊은 침잠 |

중립 밴드 0.5, 최소 표본 3은 `MOOD_NEUTRAL_BAND`·`MOOD_MIN_SAMPLE` 상수다.

## 다양성 (`diversityLabel`)

Shannon entropy를 최대 entropy로 정규화(0..1)한 값과 감정 가짓수로 판정한다.

- 1가지 → 한 감정에 집중
- 3가지 이하 또는 정규화 entropy < 0.6 → 두세 감정이 교차
- 그 외 → 여러 감정이 혼재

## 이동 (`moveLabel`)

이전 기록 월 대비 Δv·Δa가 0.4(`MOVE_THRESHOLD`)를 넘을 때만 방향을 말한다.
그 미만은 "이전 달과 비슷함" — 잡음을 서사로 만들지 않는다.
