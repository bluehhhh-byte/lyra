# lyra.cyno 디자인 브리프

한 사람이 듣고 본 것을 시간의 순서로 남기는 개인 아카이브. Lyra는 음악을, Cyno는
영화를 맡는다. 이 문서는 두 세계가 공유하는 화면·컴포넌트·토큰·상태를 정의한다.

> 웹 버전: https://claude.ai/code/artifact/0a33da74-d3b7-45a8-b57d-bc7707f0d046

## 1. 디자인이 지켜야 하는 제품 원칙

PRD의 다섯 원칙 중 화면에 직접 나타나는 것들. 기능을 그리기 전에 이 표와
충돌하지 않는지 먼저 본다.

| 원칙 | 화면에서의 의미 |
|---|---|
| 원문은 고치지 않는다 | 가사 화면에서 원문 줄이 항상 최상위 위계. 번역·독음·메모는 원문에 종속된 보조 줄로만 그린다. |
| 해석은 결정적이다 | 월간·연간 분석 문장은 계산 결과다. "AI가 써주는 감상" 같은 연출 금지 — 같은 데이터면 같은 화면. |
| 모르면 모른다고 쓴다 | 표본 3곡 미만이면 "판단 유보"를 그대로 보여준다. 빈 화면을 억지 문장으로 채우지 않는다. |
| 기록이 주어다 | 카피는 "이달의 기록은 불안이 두드러진다"처럼 쓴다. 사용자를 판정하는 문장·심리검사식 표현 금지. |
| 제품이 아니다 | 사용자 1명, 가입·광고 없음. 온보딩·전환 유도 UI를 만들지 않는다. 모든 페이지 하단에 저작권·개인 감상 고지. |

## 2. 사용자 플로우

핵심은 **기록을 되읽는 방식**이다. 모든 공개 플로우는 하나의 기록(곡·영화·하루)으로
수렴하고, 관리자 플로우만 반대 방향(기록을 만드는 쪽)으로 흐른다.

**A. 되읽기** — 가장 잦은 경로

> 홈(최근 기록일의 분석) → 음악 컬렉션 → **곡 상세**(가사+번역 병렬) →
> 연 해설·코멘트(listen_when 한 줄 포함) → 같은 날 기록(곡↔영화 교차)

**B. 아카이브** — 시간축으로 내려가기

> /archive(연·월 캘린더) → 감정 궤도(Russell 평면, 월별 중심) →
> 하루(/archive/[day]) → 테마(/archive/[day]/[theme]) → **곡·영화 상세**

**C. 공유** — 기록을 밖으로

> 곡 상세 → 연 hover(캐러셀 아이콘) → **캐러셀 편집기**(모달, 5장 미리보기) →
> 가사 최대 21줄 선택 → PNG 5장 저장(1080×1350)

**D. 등록** — 관리자 전용

> /admin 로그인(쿠키 lyra_admin) → 외부 검색(Apple, 등록 여부 표시) →
> 가사 붙여넣기(원문 그대로) → **분석**(Gemini 1회: 태그·코멘트·감정·문구) →
> 저장(DB 기록 → 캐시 무효화 → 즉시 반영)

**등록은 커밋을 만들지 않는다.** 저장 한 번 = GitHub 커밋 하나였던 구조가 계정
플래그의 원인이었다. 저장 경로에 배포·커밋을 다시 끼워 넣는 설계는 금지(PRD §6).

## 4. 화면별 레이아웃

본문 프레임은 `max-w-5xl`(1024px) 중앙 정렬, 읽기 열은 `max-w-2xl`(672px).
모든 상자는 직각 — 상호작용 표면이 종이와 만나는 곳은 전부 square edge
(globals.css의 최종 가드).

**홈 `/`** — *The Words that Shaped the World*
```
[Lyra. 로고] [음악 · 영화 · 아카이브]        [⌘K] [테마]
┌────────────────────────────────────────────┐
│ 최근 기록일의 분석 — 세리프 표제 + 결정적 문장 │
└────────────────────────────────────────────┘
음악 컬렉션 (h2 18px) + 한 줄 소개
[카드] [카드] [카드]  ← 45ms 간격 rise-in, 최대 500ms
footer — 저작권·개인 감상 고지
```

**곡 상세 `/songs/[slug]`** — 원문이 위계의 꼭대기
```
[← 뒤로]
[아트] 제목 (한글 번역) · 아티스트 (독음)
       국가 · 장르 · 연도 · 재생/공유
▎코멘트 블록 — border-l-2 accent, listen_when 한 줄 굵게
[Verse] 원문 줄 (sans)
        > 번역 줄 (바탕체, 대비 ≥84%)
        + 독음 줄 (muted)
연 hover → 복사 · 캐러셀 버튼 (44px, sm에선 hover 노출)
같은 날 기록 · 같은 아티스트 · 수록 작품
```

**아카이브 `/archive`** — 캘린더 → 궤도 → 하루
```
연 선택 · 월 캘린더 (기록 있는 날만 활성)
감정 궤도 — Russell 평면 SVG, 월별 중심점
  (pathLength=1 드로잉, 시작점 pulse)
월간 분석 문장 — 표본 부족 시 "판단 유보"
시간축 일대기 → 하루 목록으로 하강
```

**관리자 등록 `/admin`** — 3단계 + 등록곡 목록
```
[1 검색] [2 가사] [3 확인]
외부 결과 카드 — "등록됨" 칩으로 중복 예방
저장 충돌 시: 오류 + "기존 곡 페이지 보기" 링크
등록곡 목록 — 표지(클릭=곡 페이지) · 제목 · 「listen_when」
  가사 분석 후: 새 문구 + [이전] 칩으로 덮인 문구 병기
```

### 캐러셀 커버 카드 해부 — 1080×1350, 5장 묶음의 1장

1. **아트 상자 고정.** 1·2장이 같은 상자(1080×1000)로 사진을 잘라야 넘길 때
   사진이 확대·이동해 보이지 않는다.
2. **스크림.** 문구가 앉을 때 어둠막을 360px로 끌어올린다(없으면 120px).
   경계가 딱 떨어지면 잘라 붙인 티가 난다.
3. **listen_when 머리글.** 800 weight, 72→42px에서 두 줄 안에 드는 최대 크기.
   액센트 바 8px + 그림자 한 겹.
4. **제목·정보.** 제목 세리프 52→32px(번역은 10pt 작게), 아티스트 36→24px,
   메타 28px. 정보 줄의 바닥은 태그 줄 크기에서 계산 — 상수 재조정 없이
   크기를 키울 수 있다.
5. **태그 줄.** 29px 한 줄(기준선 H−52), 넘치면 끊는다. 워드마크 폭만큼 비워 둔다.

## 6. 디자인 토큰

원천은 `app/globals.css`의 `@theme` 블록 하나다. Tailwind v4가 토큰을 CSS 변수로
내보내므로 값 교체만으로 전체 테마가 바뀐다 — 컴포넌트에 색을 직접 쓰지 않는다.

### 컬러 — 다크가 기본, 라이트는 선택

다크 모드는 스크래치보드다: 검은 왁스 아래 크레용 층, 긁어낸 자리에서만 색이
드러난다. 라이트는 원래의 크림 종이. OS 설정을 따르지 않고 다크가 기본이며,
라이트는 독자가 고를 때만 `data-theme`로 적용된다(첫 페인트 전 차단 스크립트가
스탬프 — 플래시 없음).

| 토큰 | Dark (기본) | Light (선택) | 쓰임 |
|---|---|---|---|
| bg | `#12100e` | `#f6f1e4` | 종이 |
| surface | `#211d19` | `#efe8d6` | 카드·입력 |
| line | `#40382f` | `#d8cfba` | 테두리 |
| ink | `#eee7d2` | `#2a251f` | 본문 |
| muted | `#a89f8d` | `#70685a` | 보조 |
| accent | `#c8b6ff` | `#6244cc` | 라벤더 — 라이트는 대비 확보용 심화 |

**액센트는 한 벌에 하나다.** 라이트에서 #c8b6ff를 그대로 쓰면 크림 종이 위에서
대비가 무너진다 — 같은 자리, 같은 역할, 다른 값. 선택 영역·포커스 링·ink-action
섀도가 전부 이 하나의 토큰을 공유한다.

### 타입 스케일

| 역할 | 크기/두께 | 서체 |
|---|---|---|
| 캐러셀 머리글 (canvas) | 72→42 / 800 | Pretendard |
| 페이지 표제 h1·h2 | 화면별 / 700, −0.015em | Charter 세리프 |
| 섹션 제목 (text-lg) | 18 / 700 | Pretendard |
| 본문·원문 줄 | 15–16 / 400 | Pretendard |
| 번역 줄 | 동일 / 400, 대비 ≥84% | 바탕 (시스템 명조) — 원문과 서체로 구별 |
| 메타·보조 (text-xs) | 12 / 400–500 | Pretendard, muted |
| 상태 칩·eyebrow | 10–11 / 700, +0.12em, 대문자 | Pretendard |

**서체 3역할.** 제목=Charter 세리프(로컬 스택, 웹폰트 없음),
UI·원문=Pretendard(dynamic-subset), 번역=시스템 바탕. 캔버스(캐러셀)는 문서에
로드된 weight만 쓸 수 있다 — 새 weight는 `LYRIC_CAROUSEL_FONT_FACES`에 선등록.
안 하면 조용히 폴백 서체로 그려진다.

### 간격 · 형태 · 모션

| 토큰 | 값 | 쓰임 |
|---|---|---|
| 프레임 | max-w-5xl(1024) / 읽기 열 max-w-2xl(672) / 여백 px-5 | 모든 공개 화면 공통 |
| 간격 스케일 | Tailwind 4px 기반 — gap-3·4·5, 섹션 mb-14 | 형제 요소는 gap으로, 개별 마진 금지 |
| radius | 0 (전역 강제) | 버튼·입력·카드 전부 직각. 예외 없음 |
| 터치 타겟 | 44px (min-h-11 · min-w-11) | 아이콘 버튼·모바일 링크의 최소 |
| ease-out-strong | `cubic-bezier(.23,1,.32,1)` | 등장·UI 반응. 내장 easing 금지 |
| ease-drawer | `cubic-bezier(.32,.72,0,1)` | iOS풍 바텀 시트 |
| rise-in | 0.55s, 지연 i×45ms (상한 500ms) | 카드 캐스케이드 — 긴 목록 꼬리를 기다리게 하지 않는다 |
| 캐러셀 캔버스 | 1080×1350 · pad 96 · 아트 1000 · 가사 행간 1.32 | 내보내기 전용 스케일 (화면 스케일과 별개) |

## 7. 상태 — 빈 화면 · 로딩 · 에러 · 성공

이 제품의 빈 상태는 특별하다: 채우라고 조르는 대신 "표본이 부족하다"고 정직하게
말한다. 모르는 것은 모른다고 쓰는 원칙의 화면 버전.

| 상태 | 어디서 | 처리 |
|---|---|---|
| 빈 화면 | 월간 분석 (감정 곡 3곡 미만) | "판단 유보" — 억지 문장으로 채우지 않고 유보를 그대로 노출 |
| 빈 화면 | 가사 없는 곡 | `instrumental`/`lyrics_none` 표기 + 사유 한 줄. 진단 대기열에서도 제외 |
| 로딩 | Suspense 경계 | 문장형 폴백 "음악 컬렉션을 불러오는 중…" — 스피너·스켈레톤 없음, 톤 유지 |
| 로딩 | 캐러셀 렌더 | `fonts.ready` 대기 후 그린다 — 폴백 서체로 먼저 그려지는 것 방지 |
| 에러 | DB 응답 없음 (읽기) | 파일 백업 폴백으로 조용히 살아남고 `/api/version`의 contentFallback이 보고 |
| 에러 | DB 응답 없음 (쓰기) | 폴백 없이 실패를 그대로 — 환경변수 BOM까지 의심하는 구체적 오류 문장 |
| 에러 | 등록 시 slug 충돌 | 오류 + "기존 곡 페이지 보기" 행동 제공. 막다른 오류 금지 |
| 에러 | 전역 (error.js / not-found.js) | 같은 토큰·같은 톤의 전용 화면. 흰 스택트레이스 노출 금지 |
| 성공 | 곡 저장 | 즉시 반영 (태그 무효화) — 성공 모달 없이 결과 자체가 확인 |
| 성공 | 가사 분석 | 목록 행이 새 값으로 갱신 + 덮인 옛 문구를 [이전] 칩과 함께 병기 — 조용한 덮어쓰기 금지 |
| 성공 | 연 복사 | 버튼 라벨이 "복사됨"으로 잠깐 교체 — 토스트 없음 |

## 8. 접근성 노트

전부 코드에 이미 있는 규칙이다. 새 화면이 이 목록을 깨면 회귀다.

- **포커스 링.** `:focus-visible`에 액센트 2px 아웃라인 — 앱 전체가 필·아이콘
  버튼이라 UA 기본만으로는 보이지 않았다. 마우스·터치에는 나타나지 않는다.
- **터치 타겟 44px.** 아이콘 버튼은 `min-h-11 min-w-11`. hover에만 뜨는 연
  버튼(sm:opacity-0)도 포커스로 접근 가능해야 한다.
- **iOS 확대 방지.** 640px 미만에서 input·textarea·select는 16px 강제 —
  16px 미만 폼에 포커스하면 iOS가 화면을 확대한다.
- **모션 감소.** `prefers-reduced-motion`에서 카드 캐스케이드·reveal·궤도
  애니메이션 전부 제거하고 최종 상태로 정지.
- **대비.** 번역 줄 잉크는 84% 불투명도 이상(디자인 계약 테스트가 강제).
  라이트 모드 액센트는 대비 확보를 위해 별도 값. 라이트에서 antialiased는
  글자를 얇게 만들어 해제.
- **이름 있는 컨트롤.** 아이콘 버튼 전부 aria-label("이 구절로 인스타그램
  캐러셀 만들기" 등). 모달은 role=dialog + aria-modal.
- **sr-only 함정.** `<table>`에 sr-only를 직접 걸면 width:1px이 안 먹혀 문서
  폭이 늘어난다 — div로 감싼다 (실사고).
- **키보드 검색.** ⌘K/Ctrl+K로 검색 다이얼로그. 입력 필드 포커스 상태를 존중.
- **인쇄.** 가사 화면은 인쇄 스타일 별도 — 내비·버튼·오디오 제거, 흑백 강제,
  연 단위 break-inside 방지.
- **view-transition 폴백.** 테마 전환의 원형 확장은 미지원 브라우저에서 즉시
  전환으로 자연 저하.
