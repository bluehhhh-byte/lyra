# Lyra · Cyno 개선 과제 진행 대장

출처: `lyra-cyno-100-improvements-prompt.md` · 한 배치에 위에서부터 5건씩 진행한다.

## 5. 개선 과제 100건

각 항목은 `[ ]` 미완, `[x]` 완료다. **이 목록을 `docs/IMPROVEMENTS-100.md`로 복사해
저장소 안에서 관리한다.** 세션이 끊겨도 상태가 남는 곳은 거기뿐이다.

카테고리별 우선순위는 A → J 순이 아니다. **위에서부터 순서대로** 하되, 막히면 건너뛰고
사유를 적어라.

### A. Cyno — 영화 (12건)

`movies/*.md` 기록은 50편인데 별점 평가는 **1,045편**이다. 이 격차가 Cyno의 가장 큰 미개발
영역이다. 1,045편에는 감독·배우·장르·국가·러닝타임·연도·포스터가 이미 들어 있다
(`data/watcha-movies.json`). 글이 없을 뿐 데이터는 있다.

- [x] **A-01 · 별점 분포 화면**
  1,045편의 ★ 분포를 히스토그램으로, 연도별 평균 별점 이동을 선으로 보여준다.
  - 근거: 평균 ★3.32라는 숫자만 테스트에 있고 화면이 없다
  - 파일: `app/watched/`, `lib/watched.js`
  - 완료: 분포와 연도별 이동이 한 화면에 있고, 계산은 결정적이다(같은 데이터 → 같은 결과)

- [x] **A-02 · 감독별 편애와 기피**
  감독별 평균 별점을 전체 평균과 비교해 위아래로 세운다.
  - 근거: `lib/taste.js`에 "표본 부족 그룹은 순위에서 제외" 로직이 이미 있다. 영화에도 같은 규칙을 쓴다
  - 파일: `lib/watched.js`, `app/watched/taste/`
  - 완료: **표본 3편 미만 감독은 순위에서 뺀다.** 뺐다는 사실을 화면에 적는다

- [x] **A-03 · 장르 × 별점 교차**
  장르별 편수와 평균 별점을 함께 놓아 "많이 보는 것"과 "높게 주는 것"의 차이를 드러낸다.
  - 파일: `lib/genre.js`, `lib/watched.js`
  - 완료: 편수 축과 별점 축이 분리돼 있고, 표본 부족 장르는 유보 표시

- [x] **A-04 · 국가·지역 분포**
  `country` 필드로 관람 지역 분포를 표로 만든다. 지도는 만들지 마라(번들만 커진다).
  - 파일: `lib/watched.js`
  - 완료: 표 하나. 미분류(`country` 빈 값) 건수도 함께 표시

- [x] **A-05 · 러닝타임 분포와 시기**
  `runtime`으로 분포를 내고, "긴 영화를 몰아 본 시기"가 있는지 시간축과 겹친다.
  - 파일: `lib/watched.js`
  - 완료: 분포 + 시기. runtime이 빈 항목은 집계에서 빼고 그 수를 표시

- [x] **A-06 · 글 없는 고평점 영화 대기열**
  ★4.5 이상인데 `movies/*.md`가 없는 편을 목록으로 뽑아 관리자에 띄운다. 다음에 쓸 글의 후보다.
  - 근거: 1,045편 중 기록은 50편. 무엇부터 쓸지 고르는 근거가 지금 없다
  - 파일: `lib/publish-candidates.js`(이미 있음 — 확장), `app/admin/publish-queue/`
  - 완료: 별점 내림차순 목록. 이미 글이 있는 편은 안 나온다

- [x] **A-07 · 감독 한 명의 전작 보기**
  감독 이름으로 그 사람의 관람 기록 전부를 한 화면에 모은다.
  - 파일: `app/people/[name]/`, `lib/people.js`
  - 완료: 감독 축에서 별점·연도가 함께 보인다

- [x] **A-08 · 자주 본 배우**
  `cast` 배열을 평탄화해 빈도를 낸다.
  - 근거: `lib/taste.js`에 "배열 키(출연진) 평탄화" 테스트가 이미 있다. 화면이 없을 뿐
  - 파일: `lib/watched.js`, `app/people/`
  - 완료: 상위 배우 목록 + 각각의 평균 별점(표본 3편 이상만)

- [x] **A-09 · 재관람 탐지**
  같은 작품이 여러 번 기록됐는지 찾아 표시한다. 재관람은 별점 변화가 있으면 더 의미 있다.
  - 파일: `lib/watched.js`
  - 완료: 재관람 목록. 없으면 "없음"을 명시(빈 화면 금지)

- [x] **A-10 · 영화 상세에 감독 다른 작품의 별점**
  50편 상세에서 그 감독의 다른 관람 기록(별점만 있는 것 포함)을 잇는다.
  - 파일: `app/movies/[slug]/`
  - 완료: 상세에서 감독 축으로 1,045편 쪽으로 건너갈 수 있다

- [x] **A-11 · 관람 연대기**
  1,045편을 시간축에 놓아 "많이 본 시기"와 "비어 있는 시기"를 보여준다.
  - 파일: `app/watched/`
  - 완료: 연·월 밀도. 날짜가 없는 항목 수를 함께 표시

- [x] **A-12 · 포스터 없는 항목 폴백**
  `poster`가 비었거나 TMDB가 404를 내는 항목에 회색 자리표시자를 준다.
  - 근거: 곡 목록에서 같은 버그가 있었다 — `s.artwork` 없는 곡에 빈 `<img src>`를 렌더링했다
  - 파일: `app/watched/`, `app/movies/`
  - 완료: 빈 `src` 속성이 DOM에 남지 않는다. 테스트 1개

### B. Lyra — 음악·가사·번역 (12건)

곡 937개는 가사와 번역이 전부 있고 결손 0건이다. 그러니 여기 과제는 **채우기가 아니라
읽는 방법**이다.

- [x] **B-01 · 번역만 읽는 화면**
  7,000줄 넘게 쌓인 번역을 곡과 무관하게 이어 읽는 화면을 만든다.
  - 근거: `docs/PROJECT.md` §5.3-4에 명시된 계획. "번역만 따로 읽을 방법이 없다"
  - 파일: 새 라우트 `app/translations/`
  - 완료: 번역 줄 + 원곡 링크. **정적 생성하되 전량이 아니라 페이지 단위**로 자른다

- [x] **B-02 · 번역문 기준 검색**
  지금 검색이 원문만 훑는지 확인하고, 번역 텍스트도 대상에 넣는다.
  - 파일: `lib/search-index.js`, `app/api/search/lyrics/route.js`
  - 완료: 한국어 번역어로 외국곡이 검색된다. 인덱스 증가분을 보고에 적는다

- [x] **B-03 · 독음 토글**
  일본곡의 `+ ` 독음 줄을 켜고 끄는 스위치. 지금은 항상 보이거나 항상 없다.
  - 파일: `app/songs/[slug]/`
  - 완료: 독음이 있는 곡에만 스위치가 뜬다. 선택은 기억된다

- [x] **B-04 · 반복 후렴 접기**
  같은 원문이 곡 안에서 3회 이상 반복되면 접어서 길이를 줄인다.
  - 파일: `lib/songs.js`(파싱은 그대로), 표시 레이어에서만
  - 완료: **원문 데이터는 건드리지 않는다.** 접기는 표시 전용. 테스트 1개

- [x] **B-05 · 연 해설(`//`) 표시 개선**
  `//` 줄이 가사와 시각적으로 덜 구분된다. 여백과 색으로 분리한다.
  - 파일: `app/songs/[slug]/`
  - 완료: 해설이 가사로 오독되지 않는다

- [x] **B-06 · 아티스트 안 번역 일관성**
  - **2026-08-27 소유자 결정으로 제거됨.** 아티스트별 교차 진단(artistTranslationVariants)과 관리 도구의 '번역 검토 후보' 탭을 들어냈다. 곡 안 변형 알림(수정 폼)은 유지. **다시 만들지 마라.**
  같은 아티스트의 여러 곡에서 같은 표현이 다르게 번역된 곳을 찾는다.
  - 근거: `lib/translation-variants.js`가 곡 **안**의 변형은 잡는다. 곡 **사이**는 못 잡는다
  - 파일: `lib/translation-variants.js` 확장
  - 완료: 관리자에서만 보인다. **자동으로 고치지 마라** — 보여주기만

- [x] **B-07 · 가사 어휘 통계**
  자주 나오는 어휘를 곡·연도별로 집계한다.
  - 근거: `data/motifs.json`과 `scripts/build-motifs.mjs`가 이미 있다. 화면을 붙인다
  - 파일: `app/songs/motifs/`
  - 완료: 계산은 결정적. AI 호출 없음

- [x] **B-08 · 곡 상세에 미번역 줄 표시**
  번역이 안 붙은 줄이 남아 있으면 상세에서 조용히 표시한다.
  - 근거: 현재 결손 0건이지만 새 곡을 넣으면 다시 생긴다. 눈에 보여야 한다
  - 파일: `app/songs/[slug]/`, `lib/admin/needs.js`의 판정을 재사용
  - 완료: **판정 규칙을 새로 만들지 마라.** `needs.js` 한 곳만 쓴다

- [x] **B-09 · 발매연도와 기록연도의 간극**
  1970년대 곡을 2026년에 기록하는 패턴이 있는지 본다.
  - 파일: `lib/archive-stats.js`
  - 완료: 간극 분포. "옛 곡을 듣는 시기"가 있으면 드러난다

- [x] **B-10 · 앨범 단위 묶어보기**
  같은 앨범의 곡이 여러 개면 앨범으로 묶어 보여준다.
  - 파일: `app/songs/[slug]/`, `lib/songs.js`
  - 완료: 앨범 1곡뿐이면 묶음을 안 만든다

- [x] **B-11 · 같은 날의 다른 기록**
  곡 상세에서 같은 날 기록한 다른 곡·영화로 건너간다.
  - 근거: `/archive/[day]`가 이미 있다. 상세에서 그리로 가는 길이 약하다
  - 파일: `app/songs/[slug]/`
  - 완료: 같은 날 기록이 1건뿐이면 표시하지 않는다

  - 완료: 복사 결과에 출처가 포함된다

`lang="ko"`, `aria-label` 31곳, `prefers-reduced-motion` 3곳이 이미 있다.

- [ ] **I-01 · 포커스 링**
  키보드로 이동할 때 어디에 있는지 보이는지 확인한다.
  - 파일: `app/globals.css`
  - 완료: 모든 대화형 요소에 포커스 표시가 있다

- [ ] **I-02 · 본문 건너뛰기 링크**
  탭 첫 번째에 본문으로 건너뛰는 링크를 둔다.
  - 파일: `app/layout.js`
  - 완료: 포커스 전에는 숨어 있다

- [ ] **I-03 · 명암비**
  밝은 테마와 어두운 테마 양쪽에서 본문 대비를 확인한다. oklch 색공간이라 밝기 값이
  대비를 직접 좌우한다.
  - 파일: `app/globals.css`
  - 완료: 본문 4.5:1 이상. 미달 항목을 표로 보고

- [ ] **I-04 · 가사 구조의 스크린리더 표현**
  원문과 번역이 교대로 나오는 구조가 소리로 어떻게 읽히는지 본다.
  - 파일: `app/songs/[slug]/`
  - 완료: 번역 줄이 원문의 번역임이 표시된다(`lang` 속성 등)

- [ ] **I-05 · 글자 크기 기억**
  상세의 글자 크기 선택(s·m·l)이 다음 방문에도 남는다.
  - 완료: 저장 실패에도 기본값으로 동작. try/catch

- [ ] **I-06 · reduced-motion 확대**
  현재 3곳뿐이다. 궤도·전환·캐러셀 미리보기까지 넓힌다.
  - 완료: 움직이는 요소 전부가 존중한다

- [ ] **I-07 · 터치 목표 크기**
  모바일에서 누르기 작은 요소를 찾는다.
  - 완료: 44×44 미만 대화형 요소 목록과 수정

- [ ] **I-08 · 인쇄 스타일**
  가사 한 곡을 인쇄하면 읽을 만한지 본다.
  - 파일: `app/globals.css`
  - 완료: 내비게이션과 버튼이 인쇄에서 빠진다

- [ ] **I-09 · 파비콘과 앱 아이콘**
  `app/icon` 계열이 없다. `manifest.js`는 있는데 아이콘이 없으면 반쪽이다.
  - 완료: 탭과 홈 화면에 아이콘이 뜬다

- [ ] **I-10 · 링크 공유 미리보기**
  `opengraph-image`가 없다. 인스타그램·카카오톡에 링크를 붙일 때 미리보기가 없다.
  - 근거: 검색 색인은 막았지만 **사람이 직접 공유하는 링크는 막은 적이 없다**
  - 완료: 정적 생성. 런타임 이미지 생성은 함수 비용이 든다

### J. 데이터 무결성 (8건)

- [ ] **J-01 · source_hash 대조 자동화**
  원문이 조용히 바뀌지 않았는지 정기적으로 확인한다.
  - 근거: `pnpm verify:instagram`이 이미 대조한다. 정기 실행 경로가 없을 뿐이다
  - 완료: 검사 스크립트 1개. **원문을 고치는 경로를 만들지 마라**

- [ ] **J-02 · 보이지 않는 공백 재발 방지**
  U+2005·U+3000 같은 특수 공백을 검사에 넣는다.
  - 근거: 실제로 번역이 조용히 누락됐다. 눈으로는 안 보인다
  - 파일: `scripts/lint-data.mjs`
  - 완료: 특수 공백이 있는 줄을 보고한다. **자동으로 바꾸지 마라** — 원문일 수 있다

- [ ] **J-03 · frontmatter 스키마 검증**
  필수 키 누락과 타입 불일치를 잡는다.
  - 근거: `Number(null)`이 0이 되어 별점 41편이 별 0.0으로 표시됐다
  - 파일: `lib/admin/frontmatter.js`, `scripts/lint-data.mjs`
  - 완료: null과 0과 빈 문자열을 구분한다. 테스트 1개

- [ ] **J-04 · slug 충돌 검사**
  곡과 영화 slug가 겹치거나 재생성 시 달라지는지 본다.
  - 완료: 충돌 0건 확인. 있으면 보고만 하고 고치지 마라 — URL이 바뀐다

- [ ] **J-05 · 고아 데이터**
  DB에는 있는데 파일에 없거나 그 반대인 항목을 찾는다.
  - 근거: `dump-content.mjs --check`가 차이를 보는 기능을 이미 가지고 있다
  - 완료: 차이 목록. **자동 동기화하지 마라** — 어느 쪽이 옳은지는 사람이 판단한다

- [ ] **J-06 · 교정 근거 URL 유효성**
  `data/lyrics-corrections.json`의 근거 URL 26건이 아직 살아 있는지 본다.
  - 완료: 죽은 링크 목록. 교정 자체를 지우지 마라

- [ ] **J-07 · CRLF 정규화 검사**
  파서가 CRLF를 정규화하는데 그 전에 들어오는 경로가 있는지 본다.
  - 파일: `lib/songs.js`
  - 완료: 정규화 누락 경로 0건 확인

- [ ] **J-08 · 백업 무결성**
  `dump-content.mjs`가 만든 파일이 실제로 DB와 같은지 SHA-256으로 대조한다.
  - 근거: 이미 검증한다고 문서에 적혀 있다. **정말 그런지 확인하라**
  - 완료: 대조 결과 보고. 문서와 코드가 다르면 문서를 고친다
