# Claude 검토 프롬프트 — Cyno 영화 캐러셀

아래 내용을 Claude Code에 그대로 전달한다. Codex가 같은 기능을 구현 중이므로 이 요청에서는 파일을 수정하지 말고 읽기 전용 리뷰만 수행한다.

---

프로젝트 경로는 `C:\Users\박준성\.antigravity\.Test\lyra-cyno-carousel-release`다.

너는 Cyno 영화 캐러셀의 독립 디자인·제품·프론트엔드 리뷰어다. Codex가 구현을 진행 중이므로 **파일 수정, 커밋, push, 배포는 하지 마라.** 먼저 `CLAUDE.md`, `docs/CYNO-CAROUSEL.md`, `app/movies/movie-carousel.js`, `lib/movie-carousel.js`, `lib/caption.js`, 관련 테스트를 읽어라.

서비스 맥락:

- Lyra/Cyno는 한 사람이 사용하는 음악·영화 개인 아카이브다.
- Cyno는 영화 영역이고 Instagram 계정 `@lyra.syno`에 카드를 발행한다.
- 조회수 하락의 핵심 원인은 발행 빈도 감소였다.
- 새 글을 매번 쓰게 하는 디자인은 실패한다.
- 왓챠 별점 약 1,045편, TMDB 포스터 약 1,042편, 기존 Cyno 코멘트 약 50편을 재사용한다.
- 새 AI 생성, 새 npm 의존성, 새 DB 필드, 새 캐시는 허용하지 않는다.
- 카드는 Instagram 4:5 비율 `1080×1350`, 총 5장이다.

현재 선택한 구조:

1. 표지: 주제, 후보 편수, 대표 포스터 3장
2. 목록: 포스터 3×2, 영화 1~6
3. 목록: 영화 7~12
4. 목록: 영화 13~18
5. 작품노트: 목록 중 한 영화의 기존 Cyno 코멘트

사람은 주제만 고른다. 영화 선택, 별점순 정렬, 포스터 배치, 초과 편수, 캡션은 자동이다. 제작 화면은 `/movies`에서 열고 모바일 공유 시트 또는 순차 PNG 다운로드를 사용한다.

다음 질문에 근거를 들어 답해라.

1. 이 혼합형이 작품노트형·순수 목록형보다 발행 빈도와 Cyno 정체성을 함께 지키는 최선의 기본형인가?
2. 1장, 2~4장, 5장의 정보 위계와 글자 크기, 포스터 비율, 대비에 치명적인 문제가 있는가?
3. 3×2 포스터에서 Instagram 모바일 화면으로 읽을 때 제목·연도·별점이 충분히 보이겠는가? 3×3보다 이 구성이 나은지도 검토해라.
4. 주제 프리셋과 정렬 규칙이 단조로운 결과나 반복 발행을 만들 가능성은 무엇인가?
5. 포스터 프록시, 5개 동시 로딩, 실패 대체 카드, Canvas 메모리와 Object URL 정리에 문제가 있는가?
6. 모바일 편집 모달, 공유 시트, 순차 다운로드의 UX와 접근성에 빠진 경계 조건은 무엇인가?
7. Vercel Hobby와 Neon 무료티어를 유지하면서 배포하는 가장 안전한 절차는 무엇인가? GitHub 계정 플래그로 Git 연동 배포는 작동하지 않는다.
8. 현재 릴리스에서 반드시 고칠 것과 다음 릴리스로 미룰 것을 분리해라.

출력 형식:

1. 최종 판단 — 유지 / 수정 후 유지 / 구조 변경 중 하나
2. 반드시 수정 — 심각도순, 정확한 파일과 이유
3. 디자인 수치 제안 — 카드별 글자 크기·여백·포스터 영역
4. UX 경계 조건
5. 무료티어·배포 위험
6. 다음 릴리스 후보

칭찬이나 일반론보다 실제 코드와 데이터 흐름에서 확인한 문제를 우선하라. 발견하지 못한 것은 추측으로 만들지 말고 `확인된 문제 없음`이라고 적어라.
