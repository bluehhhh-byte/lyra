# Claude 검토 프롬프트 — 관리자 전용 Cyno 캐러셀

프로젝트의 Cyno 캐러셀을 제품·편집 디자인·프론트엔드 관점에서 독립 검토해 줘. 파일 수정, 커밋, push와 배포는 하지 말고 문제와 개선안만 근거와 함께 보고해.

먼저 다음 파일을 읽어.

- `docs/CYNO-CAROUSEL.md`
- `app/admin/cyno-carousel/page.js`
- `app/admin/cyno-carousel/carousel-studio.js`
- `app/admin/movie/page.js`
- `app/movies/page.js`
- `lib/movie-carousel.js`
- `lib/movie-carousel.test.mjs`
- `lib/movie-carousel-design.test.mjs`
- `middleware.js`

제품 계약은 다음과 같아.

1. 제작 기능은 공개 `/movies`가 아니라 인증된 `/admin/cyno-carousel`에만 있어야 한다.
2. 기본 작업은 영화 한 편을 골라 `표지, 기본 설명, 줄거리, 주요 내용, 감상 포인트`의 5장을 자동 생성하는 것이다.
3. 여러 영화를 묶는 기능은 별도 `주제별 큐레이션`이며, 고정 프리셋이 아니라 키워드·콘셉트 관련도로 최대 18편을 자동 선정해야 한다.
4. 저장된 줄거리와 감상문을 우선 사용하고, 자료가 부족할 때 사실을 창작하지 않아야 한다.
5. 모든 PNG는 1080×1350이고 390px 모바일 제작 화면은 가로로 넘치지 않아야 한다.
6. 공개 페이지에 왓챠 1,045편이나 상세 본문을 제작 목적으로 직렬화하면 안 된다.

다음 순서로 검토해.

- 보안 경계: 공개 진입점·우회 경로·API 인증
- 정보 설계: 두 모드가 섞이지 않는지, 기본 흐름이 한 편 캐러셀인지
- 편집 품질: 각 장의 역할, 문구 중복, 긴 줄거리와 짧은 기록의 fallback
- 자동 선정: 관련도 점수의 편향, 검색어가 없거나 결과가 적을 때의 행동
- 모바일 UX: 390px 폭, 스크롤, 입력과 미리보기 우선순위, 터치 영역
- 성능: 서버 직렬화, 포스터 동시성, 불필요한 재렌더링과 object URL 정리
- 접근성: 이름, 상태 알림, 키보드 조작, 색 대비
- 테스트 누락: 현재 계약 테스트가 놓치는 실제 회귀

각 항목은 `심각도 / 근거 파일·코드 / 사용자 영향 / 가장 작은 수정안` 형식으로 작성해. 마지막에는 배포 차단 문제와 후속 개선을 분리하고, 문제가 없다고 판단한 항목도 확인 근거를 한 줄로 남겨.
