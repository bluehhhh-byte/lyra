# 테마 명암비 감사

2026-08-27 WCAG sRGB 상대 휘도 공식으로 `node scripts/audit-contrast.mjs`를 실행했다. 일반 크기 텍스트 기준 4.5:1을 사용했다.

| 조합 | 어두운 테마 | 밝은 테마 |
| --- | ---: | ---: |
| ink / bg | 16.62:1 | 16.90:1 |
| ink / surface | 15.44:1 | 15.47:1 |
| muted / bg | 5.68:1 | 5.59:1 |
| muted / surface | 5.28:1 | 5.12:1 |
| accent / bg | 10.72:1 | 6.41:1 |
| accent / surface | 9.96:1 | 5.87:1 |
| bg / accent 버튼 | 10.72:1 | 6.41:1 |

최솟값은 밝은 테마 muted/surface의 5.12:1로 기준을 넘는다. 미달 조합은 0개라 색 토큰을 바꾸지 않았다.
